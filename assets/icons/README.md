# README icons

Single-colour SVGs for the headings in the repository README. GitHub cannot
load icon fonts, so each icon is the matching glyph from the Font Awesome
Free 6.7.2 webfonts vendored in `app/static/vendor/fontawesome/`, written out
as an SVG path and filled with indigo 500 (`#6366F1`), which stays readable on
both GitHub's light and dark themes.

Icons by [Font Awesome](https://fontawesome.com), licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); see
`app/static/vendor/fontawesome/LICENSE.txt`.
